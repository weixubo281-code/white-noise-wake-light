# White Noise Wake-Up Light

An English product website with original product imagery and a 15-second film.

**Live website:** https://weixubo281-code.github.io/white-noise-wake-light/

**Download the source and assets:** https://github.com/weixubo281-code/white-noise-wake-light/archive/refs/heads/main.zip

## Run locally

Extract the ZIP and open `index.html`. Keep `styles.css`, `app.js`, and `assets/` beside it. No build step, installation, or external libraries are required.

## Experience

- Responsive editorial product introduction.
- Scroll-driven desktop product gallery; swipe and arrow controls on mobile.
- Muted looping product film, pause control, and full-film dialog.
- Light and fabric details, bedside photography, daily rhythm, and FAQ.
- Keyboard access, visible focus, native dialog focus management, and reduced-motion support.

## Edit

Change copy in `index.html`, layout and colors in `styles.css`, and interactions in `app.js`. All media use relative paths suitable for GitHub Pages.

## Publishing

GitHub Pages serves the root of the `main` branch. Commits to `main` publish automatically. `.nojekyll` keeps the site as plain HTML, CSS, and JavaScript.

## Content

Descriptions follow the supplied product's light, white noise function, and visible design. No unverified specifications, pricing, testimonials, or medical claims are included. The original film is preserved and audio is muted by default.
